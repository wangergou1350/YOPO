## 系统架构

YOPO 是一个基于学习的无人机自主导航系统，主要包含三个核心模块：

```
┌─────────────────────────────────────────────────────────────┐
│                      YOPO 系统架构                            │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌──────────────┐      ┌──────────────┐      ┌───────────┐ │
│  │  Simulator   │      │     YOPO     │      │Controller │ │
│  │   (C++/CUDA) │ ───> │   (Python)   │ ───> │  (C++)    │ │
│  └──────────────┘      └──────────────┘      └───────────┘ │
│        │                      │                     │        │
│        │ /depth_image         │ /so3_control/      │        │
│        │ /lidar_points        │    pos_cmd         │        │
│        │ /mock_map            │                    │        │
│        │                      │                    │        │
│        └──────────────────────┴────────────────────┘        │
│                           /sim/odom                          │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

### 三大核心包：

1. **Simulator** (环境与传感器仿真器)
   - 生成随机3D环境（森林、迷宫、溶洞等）
   - 模拟深度相机和激光雷达
   - 使用 CUDA 加速渲染（RTX 3060 可达 1000+ FPS）

2. **YOPO** (学习型规划器)
   - 基于深度学习的运动规划网络
   - 输入：深度图像 + 当前状态
   - 输出：最优轨迹命令

3. **Controller** (控制器与动力学仿真)
   - 四旋翼动力学仿真
   - SO3 姿态控制器
   - 扰动观测器

## 环境要求

### 系统环境
- **操作系统**: Ubuntu 20.04 (推荐) 或 Jetson Orin/Xavier NX
- **CUDA**: 已安装 CUDA (用于加速仿真和推理)
- **ROS**: ROS Noetic
- **Conda**: Anaconda 或 Miniconda

### 硬件要求
- **GPU**: NVIDIA GPU (推荐 RTX 3060 或更高)
- **CPU**: 多核处理器 (推荐 i9-12900K 或同等性能)
- **内存**: 至少 16GB RAM

## 安装步骤

### 1. 克隆代码仓库

```bash
git clone --depth 1 git@github.com:TJU-Aerial-Robotics/YOPO.git
cd YOPO
```

### 2. 创建 Python 虚拟环境

```bash
conda create --name yopo python=3.8
conda activate yopo
pip install -r requirements.txt
```

**requirements.txt 包含的主要依赖：**
- PyTorch (深度学习框架)
- NumPy, SciPy (数值计算)
- OpenCV (图像处理)
- rospkg, rospy (ROS Python 接口)
- TensorBoard (训练可视化)

### 3. 编译控制器和动力学仿真器

```bash
conda deactivate  # 退出虚拟环境
cd Controller
catkin_make
```

**编译内容：**
- `so3_quadrotor_simulator`: 四旋翼动力学仿真器
- `so3_control`: SO3 姿态控制器
- `quadrotor_msgs`, `uav_utils`: 工具包

### 4. 编译环境和传感器仿真器

```bash
conda deactivate
cd ../Simulator
catkin_make
```

**注意事项：**
- 需要安装 `yaml-cpp`: `sudo apt-get install libyaml-cpp-dev`
- 如果遇到 CUDA 编译错误，需要手动设置 CUDA 架构（详见 [Simulator/src/readme.md](Simulator/src/readme.md)）

**CUDA 编译错误解决方法：**
```bash
# 在 CMakeLists.txt 中找到 cuda_select_nvcc_arch_flags，替换为：
set(ARCH_FLAGS "-gencode arch=compute_86,code=sm_86")  # RTX 3060/3070/3080
# 或
set(ARCH_FLAGS "-gencode arch=compute_75,code=sm_75")  # RTX 2080/Jetson Xavier
```

## 测试预训练模型

### 步骤 1: 启动控制器和动力学仿真器

**作用**: 提供四旋翼的物理仿真和姿态控制

```bash
cd Controller
source devel/setup.bash
roslaunch so3_quadrotor_simulator simulator_attitude_control.launch
```

**参数说明**:
- `init_x`, `init_y`, `init_z`: 初始位置（默认 0, 0, 2）
- `rate/odom`: 里程计发布频率（100 Hz）

**发布的话题**:
- `/sim/odom` (nav_msgs/Odometry): 无人机的位置、速度、姿态
- `/sim/imu` (sensor_msgs/Imu): IMU 数据

**订阅的话题**:
- `/so3_control/pos_cmd` (quadrotor_msgs/PositionCommand): 位置和速度指令
- `so3_cmd`: SO3 控制指令

### 步骤 2: 启动环境和传感器仿真器

**作用**: 生成随机环境并模拟深度相机和激光雷达

```bash
cd Simulator
source devel/setup.bash
rosrun sensor_simulator sensor_simulator_cuda
```

**配置文件**: `Simulator/src/config/config.yaml`

**重要参数**:
```yaml
# 环境设置
random_map: true        # 使用随机地图
maze_type: 5            # 1:溶洞 2:柱子 3:迷宫 5:森林 6:房间 7:墙面
seed: 3                 # 随机种子
x_length: 60            # 地图 X 范围
y_length: 60            # 地图 Y 范围
z_length: 15            # 地图 Z 范围

# 传感器设置
depth_fps: 33           # 深度图发布频率
lidar_fps: 10           # 激光雷达发布频率
camera/image_width: 160
camera/image_height: 96
camera/max_depth_dist: 20.0
camera/pitch: 0         # 相机俯仰角（度）
```

**发布的话题**:
- `/depth_image` (sensor_msgs/Image): 深度图像（32FC1 格式）
- `/lidar_points` (sensor_msgs/PointCloud2): 激光雷达点云
- `/mock_map` (sensor_msgs/PointCloud2): 环境地图（1 Hz）

**订阅的话题**:
- `/sim/odom`: 无人机位姿（用于计算相机视角）

### 步骤 3: 启动 YOPO 规划器

**作用**: 基于深度图像和当前状态，生成最优飞行轨迹

```bash
cd YOPO
conda activate yopo
python test_yopo_ros.py --trial=1 --epoch=50
```

**参数说明**:
- `--trial=1`: 使用第 1 组训练权重
- `--epoch=50`: 使用第 50 个 epoch 的权重
- `--use_tensorrt=0`: 不使用 TensorRT（默认）

**配置文件**: `YOPO/config/traj_opt.yaml`

**重要参数**:
```yaml
velocity: 6.0          # 飞行速度 (m/s)
wg: 0.15              # 目标引导权重
ws: 10.0              # 平滑性权重
wa: 1.0               # 加速度权重
wc: 1.0               # 避障权重
radio_range: 5.0      # 规划范围
```

**订阅的话题**:
- `/sim/odom` (nav_msgs/Odometry): 无人机状态
- `/depth_image` (sensor_msgs/Image): 深度图像
- `/move_base_simple/goal` (geometry_msgs/PoseStamped): 目标点（可在 RViz 中点击设置）

**发布的话题**:
- `/so3_control/pos_cmd` (PositionCommand): 轨迹跟踪指令
- `/yopo_net/lattice_trajs_visual` (PointCloud2): 原始锚点轨迹（可视化）
- `/yopo_net/best_traj_visual` (PointCloud2): 最优轨迹（可视化）
- `/yopo_net/trajs_visual` (PointCloud2): 所有候选轨迹（可视化）

### 步骤 4: 可视化

**作用**: 在 RViz 中查看无人机状态、轨迹和环境

```bash
cd YOPO
rviz -d yopo.rviz
```

**可视化内容**:
- 深度图像
- 激光雷达点云
- 环境地图
- 规划的轨迹
- 无人机位姿

**交互操作**:
- 点击 RViz 顶部的 `2D Nav Goal` 按钮
- 在地图上点击设置目标点
- 无人机将自动规划路径并飞向目标

## 训练新模型

### 步骤 1: 收集训练数据

**作用**: 随机采样无人机状态，收集深度图像和环境信息

```bash
cd Simulator
source devel/setup.bash
rosrun sensor_simulator dataset_generator
```

**配置**: 在 `Simulator/src/config/config.yaml` 中修改采样参数

**数据保存位置**:
```
YOPO/
└── dataset/
    ├── depth_images/      # 深度图像
    ├── states.npy         # 状态信息（位置、速度、加速度、目标）
    └── maps/              # 环境地图
```

**采样效率**:
- 100,000 样本仅需 1-2 分钟
- 只需收集一次数据集

**数据增强**:
- 随机速度、加速度、目标方向
- 分布见 `docs/state_samples.png`

### 步骤 2: 训练模型

**作用**: 使用收集的数据训练 YOPO 网络

```bash
cd YOPO
conda activate yopo
python train_yopo.py
```

**训练时间**:
- 100,000 样本，50 epochs
- RTX 3080 GPU + i9-12900K CPU: < 1 小时

**性能优化** (推荐):
```bash
# 绑定 P-cores (仅适用于混合架构 CPU)
taskset -c 1,2,3,4 python train_yopo.py
```

**训练输出**:
- 权重保存在 `YOPO/saved/YOPO_<trial>/epoch<N>.pth`
- TensorBoard 日志保存在 `YOPO/saved/YOPO_<trial>/`

### 步骤 3: 查看训练日志

```bash
cd YOPO/saved
conda activate yopo
tensorboard --logdir=./
```

在浏览器中打开 `http://localhost:6006`

**监控指标**:
- Total Loss: 总损失
- Guidance Loss: 目标引导损失
- Smoothness Loss: 平滑性损失
- Safety Loss: 安全性损失
- Collision Loss: 碰撞损失

### 话题详细说明

#### 1. `/sim/odom` (nav_msgs/Odometry)
- **发布者**: `quadrotor_simulator_so3` (Controller)
- **订阅者**: `yopo_net` (YOPO), `network_control_node` (Controller), `sensor_simulator` (Simulator)
- **频率**: 100 Hz
- **内容**:
  - `pose.pose.position`: 位置 (x, y, z)
  - `pose.pose.orientation`: 姿态四元数 (x, y, z, w)
  - `twist.twist.linear`: 线速度 (vx, vy, vz)
  - `twist.twist.angular`: 角速度 (wx, wy, wz)
- **作用**: 提供无人机的完整状态信息

#### 2. `/depth_image` (sensor_msgs/Image)
- **发布者**: `sensor_simulator` (Simulator)
- **订阅者**: `yopo_net` (YOPO)
- **频率**: 33 Hz
- **内容**:
  - `encoding`: TYPE_32FC1 (32位浮点数)
  - `width`: 160 pixels
  - `height`: 96 pixels
  - 深度值范围: 0.04 - 20.0 米
- **作用**: 提供环境深度信息用于规划

#### 3. `/so3_control/pos_cmd` (quadrotor_msgs/PositionCommand)
- **发布者**: `yopo_net` (YOPO)
- **订阅者**: `network_control_node` (Controller)
- **频率**: 50 Hz
- **内容**:
  - `position`: 期望位置 (x, y, z)
  - `velocity`: 期望速度 (vx, vy, vz)
  - `acceleration`: 前馈加速度 (ax, ay, az)
  - `yaw`: 期望偏航角
  - `kx`, `kv`: 位置和速度增益
- **作用**: 传递轨迹跟踪指令

#### 4. `so3_cmd` (quadrotor_msgs/SO3Command)
- **发布者**: `network_control_node` (Controller)
- **订阅者**: `quadrotor_simulator_so3` (Controller)
- **频率**: 100 Hz
- **内容**:
  - `orientation`: 期望姿态
  - `force`: 期望推力
  - `angular_velocity`: 期望角速度
- **作用**: 底层姿态控制指令

#### 5. `/lidar_points` (sensor_msgs/PointCloud2)
- **发布者**: `sensor_simulator` (Simulator)
- **订阅者**: 可选（用于可视化或其他规划算法）
- **频率**: 10 Hz
- **作用**: 激光雷达点云（本项目主要用深度图像）

#### 6. `/mock_map` (sensor_msgs/PointCloud2)
- **发布者**: `sensor_simulator` (Simulator)
- **订阅者**: RViz (可视化)
- **频率**: 1 Hz
- **作用**: 完整环境地图可视化

#### 7. `/move_base_simple/goal` (geometry_msgs/PoseStamped)
- **发布者**: RViz (用户点击)
- **订阅者**: `yopo_net` (YOPO)
- **频率**: 事件触发
- **作用**: 设置目标位置

#### 8. 可视化话题 (sensor_msgs/PointCloud2)
- `/yopo_net/lattice_trajs_visual`: 原始锚点轨迹
- `/yopo_net/best_traj_visual`: 最优轨迹
- `/yopo_net/trajs_visual`: 所有候选轨迹
- **发布者**: `yopo_net` (YOPO)
- **订阅者**: RViz
- **作用**: 轨迹可视化

### 控制流程

```
1. Simulator 根据 /sim/odom 渲染深度图 (/depth_image)
                        ↓
2. YOPO 接收 /depth_image 和 /sim/odom，推理最优轨迹
                        ↓
3. YOPO 发布轨迹指令 (/so3_control/pos_cmd) 到控制器
                        ↓
4. network_control_node 计算姿态控制指令 (so3_cmd)
                        ↓
5. quadrotor_simulator_so3 执行动力学仿真，更新 /sim/odom
                        ↓
                  循环回步骤 1
```

### 包之间的依赖关系

```
┌─────────────────────────────────────────────┐
│              启动顺序                         │
├─────────────────────────────────────────────┤
│  1. Controller (提供 /sim/odom)              │
│       ↓                                      │
│  2. Simulator (需要 /sim/odom 渲染传感器)    │
│       ↓                                      │
│  3. YOPO (需要 /sim/odom 和 /depth_image)   │
│       ↓                                      │
│  4. RViz (可选，用于可视化)                   │
└─────────────────────────────────────────────┘
```

**注意**: 
- Controller 必须首先启动，因为它提供基础的 `/sim/odom` 话题
- Simulator 依赖 `/sim/odom` 来确定相机位姿
- YOPO 同时依赖 `/sim/odom` 和 `/depth_image`

## 实际飞行部署

### 修改配置

在 `test_yopo_ros.py` 的最后部分修改：

```python
settings = {
    'use_tensorrt': 1,              # 启用 TensorRT
    'goal': [50, 0, 2],
    'pitch_angle_deg': -0,
    'odom_topic': '/your_vio/odometry',      # 修改为你的里程计话题
    'depth_topic': '/camera/depth/image',    # 修改为你的深度相机话题
    'ctrl_topic': '/so3_control/pos_cmd',
    'plan_from_reference': False,
    'verbose': False,
    'visualize': False              # 关闭可视化以节省计算

```

### 相机配置

**重要**: 确保深度相机配置与训练时一致
- 预训练权重使用: 16:9 分辨率，90° FOV
- RealSense 推荐设置: 480×270 分辨率

### 坐标系
确保里程计使用 NWU (North-West-Up) 坐标系

## 常见问题

### 1. CUDA 编译错误

**问题**: `catkin_make` 失败，提示 CUDA 架构不匹配

**解决方法**:
```bash
# 编辑 Simulator/src/CMakeLists.txt
# 找到 cuda_select_nvcc_arch_flags 部分，替换为:
set(ARCH_FLAGS "-gencode arch=compute_XX,code=sm_XX")
# XX 根据你的 GPU 型号设置:
# RTX 30 系列: 86
# RTX 20 系列: 75
# Jetson Xavier: 72
# Jetson Orin: 87
```

### 2. 深度图为空或全黑

**可能原因**:
- Simulator 未正确启动
- 无人机位置超出地图范围
- 相机参数配置错误

**检查方法**:
```bash
# 查看深度图话题
rostopic echo /depth_image
# 查看 Simulator 日志
```

### 3. 无人机不移动

**可能原因**:
- 未设置目标点
- 目标点与当前位置重合
- 控制器未正确接收指令

**解决方法**:
```bash
# 在 RViz 中点击 2D Nav Goal 设置目标
# 检查话题连接
rostopic list
rostopic hz /so3_control/pos_cmd
```

### 4. 训练损失不下降

**可能原因**:
- 学习率设置不当
- 数据集质量问题
- 权重初始化问题

**解决方法**:
- 检查 TensorBoard 日志
- 重新收集数据集
- 调整 `traj_opt.yaml` 中的权重参数

### 5. 仿真帧率低

**可能原因**:
- GPU 性能不足
- CPU 性能瓶颈
- 传感器发布频率过高

**优化方法**:
```yaml
# 在 Simulator/src/config/config.yaml 中降低频率
depth_fps: 20  # 从 33 降到 20
lidar_fps: 5   # 从 10 降到 5
```

### 6. RViz 无法显示点云

**解决方法**:
```bash
# 检查 Fixed Frame 设置
# 在 RViz 中设置 Fixed Frame 为 "world" 或 "odom"
```

### 7. conda 环境冲突

**问题**: ROS 和 conda 环境冲突

**解决方法**:
```bash
# 在运行 ROS 命令前退出 conda 环境
conda deactivate
# 在运行 Python 脚本时激活 conda 环境
conda activate yopo
```

## 性能基准

### 仿真性能 (RTX 3060 + Ubuntu 20.04)

| 组件 | 频率 | 耗时 |
